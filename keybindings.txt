# Keyboard bindings. One per line: `<Key> => <Action>`.
# Lines starting with # and blank lines are ignored.
# An action left out, or a file that isn't here at all, keeps its default.
# Weapon select (1-9), the editor's own number row (1-8: shapes, tools,
# palette slots) and the editor's Ctrl+S are slot numbers and reflexes, not
# remappable actions, and aren't listed here. EditorOpenPicker is the browser
# for whatever the current editor mode places - models, sprites, items, guns,
# characters, or the texture library while the block tools are in hand.
# Every other action is listed here, whether or not it is rebound: the file is
# the list of what can be rebound, and a test fails if one goes missing.
